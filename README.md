# Football Scores App

Private Next.js + TypeScript football website prepared for Hostinger Node.js hosting.

## Current milestone
- Responsive score-centre homepage
- API-Football server-side integration
- 60-second server cache
- League and team route placeholders
- No API key committed

## Local setup
1. Use Node.js 22.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local`.
4. Add `API_FOOTBALL_KEY`.
5. Run `npm run dev`.

## Production
`npm run build` then `npm start`.
